3D Correlation Space

Goal

This site documents on-going work toward quantifying how perturbations in correlation space affect the power and stability of causal discovery algorithms.

Inference for \(\rho\)

Note: all the below theories have a corresponding z-transformed (variance stabilizing) approach. Details to be added later.

Asymptotic Distribution

Under standard regularity conditions: normality and finite asypmtotic covariance \(\Psi \in R^{p \times p}\) (and also finite fourth-order moment), CLT shows that \[ \sqrt{n}(\hat{\rho}-\rho) \xrightarrow{d} N(0,\Psi(\rho)) \]where:

  • diagonal of \(\Psi\): \(\psi_{jk} = 1-\rho_{jk}^2\)

  • off-diagonal of \(\Psi\):

    \[ \begin{aligned} \psi_{jk,hm} &= N\,\sigma_{jk,hm} \\ &= \frac{1}{2} \Big[ (\rho_{jh}-\rho_{jk}\rho_{kh})(\rho_{km}-\rho_{kh}\rho_{hm}) \\ &\quad + (\rho_{jm}-\rho_{jk}\rho_{km})(\rho_{kh}-\rho_{kj}\rho_{jh}) \\ &\quad + (\rho_{jh}-\rho_{jm}\rho_{mh})(\rho_{km}-\rho_{kj}\rho_{jm}) \\ &\quad + (\rho_{jm}-\rho_{jk}\rho_{km})(\rho_{kh}-\rho_{km}\rho_{mh}) \Big]. \end{aligned} \]

When \(\Psi(\rho)\) is unknown, we use plug-in estimate $ \Psi(\hat\rho)$. This requires us to prove \(\hat\Psi \xrightarrow{p} \Psi\).

[See Steiger (1990)]

Confidence region of \(\rho\)

Finding Pivot of \(\rho\)

A typical way to construct confidence interval for an unknown parameter is to find its pivot quantity and the corresponding distribution.

From Steiger (1990),

\[ \sqrt{n}(\hat{\rho}-\rho) \xrightarrow{d} N(0,\Psi(\rho)) \]

Let \(Z = \Psi(\rho)^{-\frac{1}{2}}{\sqrt{n}}(\hat{\rho} - \rho)\), then \(Z \xrightarrow{d} N(0,I_d)\), where \(d\) is the number of correlation coefficients (equivalent to \(\frac{p(p-1)}{2}\) in which \(p\) is the number of variables). We claim that \(Z\) is a pivot quantity for \(\rho\) since distribution of \(Z\) is free from the unknown parameter.

We can essentially use \(Z\) to construct confidence region for \(\rho\).

In the case of \(d=1\) (\(p=2\)),

\[ \begin{gathered} Z = \frac{\hat{\rho} - \rho}{\sqrt{\Psi{(\rho)}/{n}}} \sim N(0,1) \\ P(-z_{\alpha/2}\leq \frac{\hat{\rho} - \rho}{\sqrt{\Psi{(\rho)}/{n}}} \leq z_{\alpha/2}) = 1-\alpha \\ P(\hat{\rho}-z_{\alpha/2}\cdot \sqrt{\frac{\Psi{(\rho)}}{n}} \leq \ \rho \ \leq \hat{\rho}+z_{\alpha/2}\cdot \sqrt{\frac{\Psi{(\rho)}}{n}} = 1 - \alpha \end{gathered} \]

Note when \(d=1\), \(\Psi(\rho)\) is a scalar, basically variance of \(\rho\). When \(\Psi(\rho)\) is unknown, we can try its plug-in estimate: \(\Psi(\hat{\rho})\).

Some challenges arise when using \(Z\) to construct a confidence region for \(\rho\) in higher dimension:

  1. Because \(Z_i \sim N(0,1)\) for each \(i\) dimension, we are basically constructing confidence interval for each \(Z_i\) marginally. This results in a confidence “box” (or hyper-rectangle) when combined together.
  2. This approach does not respect the covariance of \(\rho\) and treat each \(\rho_{ij}\) as independent. This is incorrect. See Steiger (1990).

This motivates us to consider a joint-inference approach, so that the confidence region that we build respects the covariance of \(\rho\).

Joint Inference on \(\rho\)

By continuous mapping theorem, \(T = \ Z^TZ \xrightarrow{d} \chi^2_{d}\). Since \(T\)’s distribution is independent of unknown parameters, and that \(T= T(\hat\rho, \rho) = n(\hat{\rho} - \rho)^T\Psi(\rho)^{-1}(\hat{\rho} - \rho)\) is a function of data \(\hat\rho\) and unknown parameter \(\rho\), we can construct confidence region of \(\rho\) using pivot \(T\).

\[ C_{1-\alpha} = \{ \rho: \ n(\hat{\rho} - \rho)^T\Psi(\rho)^{-1}(\hat{\rho} - \rho)\ \leq \chi^{2}_{d, 1-\alpha} \} \]

The LHS equation is also known as the Mahalanobis distance/ Wald distance.

Interpretation:

  1. The confidence region (or confidence set) of \(\rho\) is the set of all parameter vectors whose Mahalanobis distance from the observed estimator \(\hat\rho\) is smaller than the \(\chi^2\) threshold.
  2. In other words, the set of all candidate parameter values \(\rho\) that are not too far from the observed estimator \(\hat\rho\) is the confidence region.
  3. The likelihood of the confidence set containing the true \(\rho\) is 95%.

Notes:

  1. The plug-in approach is only true when \(\Psi(\hat\rho) \xrightarrow{p} \Psi(\rho)\).
  2. If the above is true, then when \(\Psi\) is unknown, by Slutsky theorem, \(C_{1-\alpha} = \{ \rho: \ n(\hat{\rho} - \rho)^T\hat\Psi(\hat\rho)^{-1}(\hat{\rho} - \rho)\ \leq \chi^{2}_{d, 1-\alpha} \}\)
  3. I do think the confidence ellipsoid should be the intersect of \(C_{1-\alpha}\) and the PSD criteria.

Practical Considerations:

  1. When \(\Psi(\rho)\) is unknown, we can try its plug-in estimate: \(\Psi(\hat{\rho})\). This requires consistency check.

  2. We also want to check that the Wald pivot statistic using plug-in \(\Psi(\hat{\rho})\) has the correct \(\chi^2\) calibration. - See Simulation 4 (Reverse Containment Rate) for empirical check.

    \[ T^* = \ n(\hat\rho - \rho_0)^T \Psi(\hat\rho)^{-1}(\hat\rho-\rho_0) \]

    If Wald-approximation is correct using the plug-in approach, then \(P(T^* \leq \chi^2_{d, 1-\alpha}) \approx 1- \alpha\)

Sampling

Sampling distribution of \(\hat\rho\): Multivariate normal distribution (Full Wald Cloud)

We introduced that the asymptotic distribution of \(\hat\rho\) is the following:

\[ \sqrt{n}(\hat{\rho}-\rho) \xrightarrow{d} N_d(0,\Psi(\rho)) \]

which is equivalent to \(\hat\rho \sim N_d(\rho, \frac{\Psi(\rho)}{n})\) after rearranging the terms. In other words, if we know \(\rho\) and \(\Psi(\rho)\), we can obtain random \(\hat\rho\) samples following the above MVN distribution. Importantly, these samples respect the covariance of \(\rho\).

In matrix algebra notation:

\(\hat\rho = \rho + Lz\), where \(z \sim N(0,I_p)\), \(L= \frac{1}{\sqrt{n}}UD^\frac{1}{2}\) (eigen-decomposition of \(\Psi(\rho)\): \(U\) is the eigenvector, \(D\) is the eigenvalue matrix).

Interpretation: Suppose we draw 100 \(\hat\rho\)s from the sampling distribution, approximately 95 \(\hat\rho\)s will satisfy the Mahalanobis inequality, which implies that approximately 95 out of the 100 confidence regions constructed by each \(\hat\rho\)s will contain the true parameter \(\rho\):
\[ Pr_{\rho_0} (\rho \in C_{1-\alpha}(\hat\rho)) = 1-\alpha \]

Sample inside the confidence region of \(\rho\)

To achieve this, we will have to determine: (1) the boundary of \(\rho\), (2) Sampling scheme inside the boundary space (e.g., do we sample uniformly or normally?).

1. Boundary of \(\rho\)

Suppose we want to know the boundary of 95% confidence region of \(\rho\), and suppose this \(\rho\) is fixed at \(\rho_0\). The maximum mahalanobis distance is \(c= \chi^2_{d,0.95}\).

Following the matrix algebra notation in earlier section, the boundary is determined at \(\hat\rho^b = \rho_0 + L\sqrt{c}\) (Note: superscript \(b\) denotes boundary).

2. Sampling Scheme

  1. A truncated wald cloud approach: Sample from the full wald cloud, and reject samples that failed the inequality test. Caveat: we might lose 5% of samples.

  2. Sample normally inside the boundary:

    Note that the boundary is \(\rho_0 + L\sqrt{c}\). Normally distributed samples inside this region can be generated by

    \[ \hat\rho^{(b)} = \rho_0 + L(\sqrt{q} Z) \]

    where \(L= \frac{1}{\sqrt{n}}UD^\frac{1}{2}\) (eigen-decomposition of \(\Psi(\rho)\): \(U\) is the eigenvector, \(D\) is the eigenvalue matrix), \(q\) is a random sample from \(\chi^2_{d, 0.95}\), and \(Z\) represents random unit direction on each dimension, sample from \(N(0,I_p)\) and rescale to norm of 1 (i.e. \(||Z|| = 1\))

  3. Sample uniformly inside the boundary:

    \[ \hat\rho^{(b)} = \rho_0 + L(\sqrt{c} r^{\frac{1}{p}}Z) \]

    where \(c: \chi^2_{d, 1-\alpha}\), \(r\) represent a random radius sample from \(Unif(0,1)\), \(Z\) represents random unit direction on each dimension, sample from \(N(0,I_p)\) and rescale to norm of 1 (i.e. \(||Z|| = 1\)).

If the boundary is defined as \(C_{1-\alpha}\), then all resulting samples above (regardless of sampling scheme) will guarantee to fall inside \(C_{1-\alpha}\),

Interpretation:

\(c\) sets the \(1-\alpha\) chi-square cut-off that determines the confidence ellipsoid boundary; \(r\) distributes a random radius (between (0,1)) uniformly in all \(p\)-dimension within the ellipsoid; \(Z\) is the standard way to generate uniform random directions on a unit sphere. Geometrically, multiplying these three objects to \(L\)is like rotating and scaling the ellipsoid.

Practical considerations

All sampling approaches require \(\rho\) to have a well-defined covariance \(\Psi(\rho)\). If \(\Psi\) is rank-deficient, we will not be able to proceed with the sampling procedure above. Some ideas to work in later stage:

  1. Z-transformation on \(\rho\) could potentially help to stabilize variance. (not implemented yet)

  2. Only work within the rank-reduced space; the “null-space” will be treated as “constraints”: make pertubations using a subset of those stable dimensions / variables. In this case, degree of freedom will be reduced. Also, is it still chi-square?

Notes:

  1. Mahalanobis distance is no longer a valid chi-square statistic (distribution) if we are limiting samples within \(C_{1-\alpha}\) and changing the normal density to uniform. (Is this important to further deep-dive? Use the resulting distribution to calibrate more easily if the distribution is in simple closed form?)

  2. [Jon: review below again] To be more precise on the uniform sampling scheme, the uniformity refers to the ratio of the sample ellipsoid volume to the CI ellipsoid’s volume is uniform. Proof:

    Given any point \(\rho\), we have

    \[ E(c) = \{ \rho : n(\rho - \rho_0)^T \Psi(\rho_0)^{-1} (\rho - \rho_0) \leq c \} \]

    where \(c=\chi^2_{p, 1-\alpha}\)

    Now suppose we have a random \(\rho\) that is \(t\) distant away from \(\rho_0\) in the Mahalanobis space:

    \[ \rho= \rho_0+ \sqrt{\frac{t}{c}} (\rho - \rho_0) \] Then

    \[ \begin{aligned} (\rho(t) - \rho_0)^T\Psi(\rho_0)^{-1} (\rho(t) - \rho_0) &= (\sqrt{\frac{t}{c}} (\rho - \rho_0))^T\Psi(\rho_0)^{-1} (\sqrt{\frac{t}{c}} (\rho - \rho_0)) \\ &= \frac{t}{c} (\rho - \rho_0))^T\Psi(\rho_0)^{-1} (\rho - \rho_0)) \\&= \frac{t}{c} \frac{c}{n} \\ &= \frac{t}{n} \end{aligned} \] Therefore,

    \[ \begin{aligned} \frac{V(E(\rho(t))}{V(E(c))} &= \frac{V(\rho_0+ \sqrt{\frac{t}{c}} (\rho - \rho_0))}{V(E(c))} \\ &= \frac{(\sqrt{\frac{t}{c}})^p \cdot V(\rho))}{V(E(c))} \\ &= \frac{(\sqrt{\frac{t}{c}})^p \cdot V(E(c)))}{V(E(c))} \\ &= (\sqrt{\frac{t}{c}})^p \\ &= (\frac{t}{c})^{(p/2)} \end{aligned} \]

    Note: The distance \(t\) is exactly the mahalanobis distance of a sample to \(\rho_0\). This ratio should be approximately \(Unif(0,1)\).

Simulation 1: Empirical distribution of the observed test statistic (mahalanobis distance/ wald).

Goal: To assess whether the empirical distribution of the simulated Wald test statistic matches the theoretical \(\chi^2\) density under \(H_0\)​, which validates the chi-square calibration of the procedure, including Type-1 error and coverage.

Simulation Flow:

Input: True R \(\rho_0\), sample size \(n\), significance level \(\alpha\), number of replicates \(B\)

Output: Test statistic (mahalanobis distance) \(T_b\)

for \(b\) \(\leftarrow\) 1 to \(B\):

  1. Sample \(\hat\rho^{(b)}\) from Wald-cloud (or equivalently, normal distribution)

  2. Compute covariance \(\Psi(\hat\rho^{(b)})\)

  3. Compute test-statistic (mahalanobis distance): \(T_b \leftarrow n(\hat{\rho}^{(b)}-\rho_{0})^{\top}[\Psi(\rho_{0})]^{-1}(\hat{\rho}^{(b)}-\rho_{0})\)

return \(T_b\)

Note: When true variance is known, use \(\Psi(\rho_0)\). When true variance is unknown, \(\Psi(\hat\rho^{(b)})\) can be a good estimate of

The histogram shows the empirical distribution of the observed test statistics \(T_b\) from simulation, the red curve shows the theoretical \(\chi^2\) density under \(H_0\)​.

Simulation 2: Nominal vs Actual Coverage

Goal is to validate:

\[ Pr_\rho(\rho \in C_{1-\alpha}(\hat\rho)) = 1-\alpha \]

Frequentist interpretation of confidence region: Over repeated samples, the confidence region (which is random, depends on sample) contains the fixed true \(\rho\) with probability \(1-\alpha\).

Simulation Flow: Monte Carlo estimate of coverage of \(C_{1-\alpha}(\hat{\rho})\)

Input: \(\rho_0\), \(\Psi(\rho_0)\), sample size \(n\), significance level \(\alpha\), number of replicates \(B\)

Output: Coverage level \(C_{1-\alpha}(\hat\rho)\)

\(H \leftarrow 0\)

for \(b\) \(\leftarrow\) 1 to \(B\):

  1. Sample \(\hat\rho^{(b)}\) from Wald-cloud (or equivalently, normal distribution)

  2. Compute covariance \(\hat\Psi(\hat\rho^{(b)})\)

  3. Compute test-statistic (mahalanobis distance): \(T_b \leftarrow n(\hat{\rho}^{(b)}-\rho_{0})^{\top}[\hat\Psi(\rho_{0})]^{-1}(\hat{\rho}^{(b)}-\rho_{0})\)

  4. if \(T_b \leq \chi^2_{p,1-\alpha}\), then \(H \leftarrow H+1\) ;

return \(H /B\) (actual coverage)

Simulation 3: CDA Power Analysis based on different perturbation schemes

Benchmark targets:

  1. \(G_0\) (Ghalo): the true causal graph from DAO
  2. \(G_0hat\) : the graph obtained by running a CDA on the population matrix \(R_0\), using a finite sample size parameter.

Procedure:

  1. Generate 200 graphs from DAO (Nodes: 30, AD: 2), and each graph consists of 300 bootstrapped samples (R1…. R300).
  2. Apply CDA (PC and BOSS) onto R1 through R300, get PC1 … PC300 and BOSS1 … BOSS300.
  3. Report performance:

      Stability threshold is currently set as 0.6. AUC part is not done.

  2. Shift simulation design:

    1. Current: Generate Rhat from the TrueR , and then make perturbations around Rhat.
    2. New: Treat Rhat as one perturbation /realization of the TrueR.

    Reasoning:

    1. Current approach reflects the real-data practical procedure. However it introduces an extra layer of noise (double-sampling). It answers the question: How much does the graph change if I jiggle the data? (Although we will need to argue which is the right way of jiggling it? around center? wald perturbations?)

Procedure:

  2. Sample 1000 \(R^{*}\)’s from \(W(\hat{R})\)
  3. For each \(R^{*}\) (i=1,…, 1000), compute mahalanobis distance between \(R_i^*\) and \(\hat{R}\):
    1. Here, we treat \(R_i^*\) as the center
    2. Estimate mahalanobis distance using the asymptotic covariance of \(R_i^*\) : \(\Psi(R_i^*)\)
  4. Instead of reporting the distance, I’m reporting:
    1. p-values (assuming the degree-of-freedom I derived is correct).
    2. How many \(R_i^*\) were ill-defined
    3. Reverse containment rate: How many \(R_i^*\) were “statistically indistinguishable” to \(\hat{R}\) under a truncation value \(\alpha_2\).

Repeat over different \(\hat{R}\)s and sample sizes.

Simulation 4 (Revised): Reverse Containment for Wald Regions in R Space

Procedure:

  1. Sample 100 \(R_0\)’s uniformly from the space of all \(p\) x \(p\) correlation matrices

  2. [ \(R_0\) as the center ] For each \(R_0\), take 1000 samples \(\hat{R_i}\)’s normally over the wald cloud \(W(R_0)\)

  3. [ \(\hat{R_i}\) as the center ] For each \(\hat{R_i}\) (i=1,…, 1000), compute its variance \(\Psi(\hat{R_i})\), measure its mahalanobis distance \(T_i\) with \(R_0\) and using \(\Psi(\hat{R_i})\).

  4. Compute p-value under the null: \(p = Pr(T \geq t \ | \ H_0)\)

  5. Define reverse containment: \(p \leq 0.05\) (or some other \(\alpha\) values).

    Output:

    1. distribution of mahalanobis distances:
      expect to follow chi-square distribution with the corresponding d.o.f.

    2. distribution of p-values:
      expect to follow \(Unif(0,1)\) for proper calibration.

    3. Reverse containment rate: How many \(\hat{R_i}\)s were “statistically indistinguishable” to \(R_0\) ? expect actual reverse containment rate \(\approx\) nominal rate defined in step 4 : \(1-\alpha\).

    4. How many \(\hat{R_i}\) s do not have full rank covariance, reject these samples.

Simulation 5: MCMC Sampling

Setup: Start with a graph \(G\) that is parametrized by \(R_0\). We observed data \(X\) with sample size \(n\) and derive sample correlation \(S\).

Procedure:

  1. Initialize a chain \(Q\) with \(S\): \(Q^{[0]} = S\)

  2. From \(t=1, .... , B\):

    Let \(R\) denote current state: \(Q^{[t]}\)

    1. Sample \(R' \sim W(R;\Psi(R, n))\)
    2. Compute acceptance ratio: \(A(R \rightarrow R') = \dfrac{f(R | R',n)}{f(R'|R,n)}\cdot\ I(S \in CR_{1-\alpha}(R') )\)

      • \(f(R| R',n)\) is the multivariate normal density of \(R\) given \(\mu = R'\) and \(\Sigma = \Psi(R')/n\)

      • \(I(S \in CR_{1-\alpha}(R') )\) is an indicator function for the reverse containment status. \(I(\cdot)=1\) if \(S\) lies within the confidence region of \(R'\) at level \(1-\alpha\). The center is \(R'\).

        More specifically, it is checking the Mahalanobis distance between \(S\) and \(R'\) with \(R'\) as the center: \((s−r′)^T \Psi(R′)^{-1}(s−r′)≤\chi^2_{d,1−α}​\), where \(d=\frac{p(p-1)}{2}\).

    3. If \(A(R→R′) >u\) where \(u \sim Unif(0,1)\), accept \(R'\): update \(Q^{[t]} = R'\). Else, \(Q^{[t]} = Q^{[t-1]} = R\)

Other notes: Burnin period was set as 20% of samples in the chain.

Others & To-explore

Marginal inference approach

  1. We discussed instead of the joint-inference approach, we could sample \(\hat\rho_{ij}\) independently from its asymptotic distribution \(N(\rho_{ij}, 1-\rho_{ij}^2)\).

    1. From simulation (similar to simulation 2 above), coverage of each \(\hat\rho_{ij}\) is close to the nominal level when considered individually. However, when we consider the results across all \(\rho_{ij}\) s jointly, the joint coverage from this marginal approach became poor. This is related to multiple testing problem.

    2. To construct a correlation matrix sample, we could sample each \(\hat\rho_{ij}\) independently from its confidence interval, and check if that constructed matrix is PSD. If it is not PSD, we reject it.

      This approach works in lower dimension, however became highly inefficient (large rejection rate) as dimension grows.

Sampling Idea (Bryan)

  1. Construct a list of Rs that only contains Rhat (the sample correlation) to begin with

  2. Uniformly pick a correlation matrix from your list of Rs (call it A)

  3. Sample a new correlation matrix (call it B) using your sampling distribution (95% confidence region using wald distance) with A as the input correlation matrix

  4. Check if Rhat is within Bs 95% confidence region and add B to your list of Rs if it is, otherwise do nothing

  5. Go to step 2 (until Rs has reached a desired size)

Notations (depreciated)

\(R\): True R, unknown

\(R_{obs}\): Observed R, typically estimate from sample data

\(R^{\prime}_{obs}\): Use superscript “\(\prime\)” to denote a perturbed object

\(\rho\): \(vech(R)\), the unique off-diagonal elements of \(R\) matrix.

\(\hat\rho\): \(vech(R_{obs})\), the unique off-diagonal elements of \(R_{obs}\)

\(\hat\rho^{\prime}\): \(vech(R^{\prime}_{obs})\), the unique off-diagonal elements of \(R^{\prime}_{obs}\)

\(\mu\): population mean

\(\Sigma\): Covariance matrix

\(\Psi\): Covariance matrix of pearson correlation coefficient

\(d\): number of variables in data

\(p\): number of parameters (length of \(\rho\)) = \(\frac{d(d-1)}{2}\)
